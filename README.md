# Weds of Bohem

> **Where Our Art Meets Your Story**  
> Creative wedding photography, cinematic films, and creator studio space based in Thrikkodithanam, Kerala.

## Overview
Weds of Bohem is a modern, responsive wedding photography and cinematography studio website featuring:
- Editorial photography showcase & curated story galleries
- Wedding films & cinema highlights
- Thrikkodithanam creative studio & editing suite details
- WhatsApp direct booking & consultation concierge (`+91 92922 55734`)
- Lightbox modal views, responsive layout, and refined typography

## Running Locally
You can serve the project using any static file server:
```bash
# Python 3
python3 -m http.server 8080
```
Open `http://localhost:8080` in your browser.
